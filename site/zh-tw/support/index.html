說明

遇到問題，或有想法？先試試下面的方法，再寫信告訴我們。

1. 快速解決

  • 手機找不到 Mac：確認 Mac 上的 ATA 是開著的、兩邊的藍牙都開著，而且手機在 Mac 旁邊（同一個房間內）。
  • 顯示連不上你的 Mac：讓手機連上和 Mac 同一個 Wi-Fi，再試一次。
  • 傳得非常慢：請看防火牆的修正方法。
  • QR code 沒反應：每個 QR code 只能用一次、5 分鐘內有效。在 Mac 上按「產生新的 QR code」，或在 ATA 視窗裡按「配對手機…」，換一個新的。
  • Mac 上的 ATA 打不開：照著安裝說明的第 3 步操作。
  • ATA 說「請先把 ATA 移到『應用程式』」：在下載的視窗裡把 ATA 拖到「應用程式」檔案夾上，再從「應用程式」打開。

更多解答：常見問題。

2. 寫信給我們

寄信到 magiclin99@gmail.com

有 GitHub 帳號的話，也可以在 GitHub 回報問題或提出建議，其他人也看得到、可以補充。

3. 方便的話，請告訴我們

  • 手機：型號與 Android 版本（設定 → 關於手機）。
  • Mac：macOS 版本（蘋果選單 → 關於這台 Mac），以及兩邊 ATA 的版本。
  • 發生了什麼：是在配對、找 Mac，還是傳送的時候？請附上 app 顯示的完整訊息或截圖。
  • Wi-Fi：兩台有沒有連同一個 Wi-Fi？沒有的話，手機是不是用行動網路？在家、在公司，還是公共 Wi-Fi？
  • 每次都會發生嗎？檔案大概多大？

請不要傳配對 QR code 的照片或任何私人檔案，我們用不到。
