技術細節

給想知道 ATA 到底怎麼運作、為什麼可以信任它的人。一般使用不需要看這一頁。

原始碼與授權

Android app、Mac app 與通訊協定規格都以 MIT 授權開放原始碼，放在同一個 repo：github.com/magiclin99/ata。協定寫在 SPEC.md（目前是繁體中文），測試向量在 spec/vectors.json，兩邊的 app 都有對照這組向量的單元測試。資安問題的回報方式請看 repo 裡的 SECURITY.md。

  • Android：Kotlin 與 Jetpack Compose，Android 9 以上（minSdk 28）。QR code 由內建的 ZXing 函式庫在手機上解讀。
  • Mac：Swift 與 SwiftUI，macOS 14 以上，通用版本（Apple 晶片與 Intel）。

一次傳輸怎麼連線

  1. 用藍牙低功耗（BLE）找到對方並交換連線資訊。Mac 是 BLE peripheral。手機連上後，雙方用 256 位元配對金鑰做雙向 HMAC-SHA256 挑戰回應（雙方各出一個 nonce），再用 HKDF-SHA256 導出各方向的 session 金鑰。之後每一則 BLE 訊息都以 AES-256-GCM（計數器 nonce）加密。
  2. 路徑一：區域網路。Mac 開一個臨時 TCP 連接埠，透過加密的 BLE 通道把自己的區網 IPv4 位址傳給手機。手機綁定在 Wi-Fi 網路上撥接，以帶長度前綴的 AES-256-GCM 記錄傳送。
  3. 路徑二：P2P 直連。TCP 連不上時，手機透過 BLE 送出完整的（非 trickle）WebRTC offer。ICE 只使用公開 STUN 伺服器 stun.l.google.com:19302 與 stun.cloudflare.com:3478，從不設定 TURN（中繼）。SDP 走在已驗證的 BLE 通道上，所以 DTLS 指紋也經過驗證。
  4. 都不通：手機會告訴你連不上 Mac。刻意不設中繼備援，所以在擋住 P2P 的網路（例如兩邊都是 symmetric NAT）會直接失敗，而不是改走伺服器。

每個檔案都附 SHA-256，Mac 比對相符後才把暫存檔改成正式檔名；不符或不完整的檔案會被刪除。實測：同一個 Wi-Fi 約 60 MB 大約 6 秒（含尋找與握手）；行動網路走 P2P 約每秒 1 MB。

配對金鑰與儲存的資料

  • 配對：Mac 顯示的 QR code 內含 16 位元組的裝置 ID 與新產生的 32 位元組金鑰，5 分鐘內有效、只能用一次。
  • Android 以不可匯出的 Android Keystore 金鑰加密後儲存，並關閉 app 備份。
  • Mac 存在 ~/Library/Application Support/io.github.magiclin99.ata.mac/pairings.json（資料夾權限 0700、檔案 0600，排除在 Time Machine 備份之外）。
  • Mac 廣播的名稱是 ATA- 加上隨機裝置 ID 的前 8 個十六進位字元，附近的藍牙掃描器都看得到。

Mac 安裝程式與簽章憑證

Mac 版沒有經過 Apple 公證（沒有加入付費的 Apple 開發者計畫），而是用一張固定的自簽憑證簽章：mac-app/signing/ata-signing-cert.pem，SHA-1 3DA39545619D4949FA758C6BECC77F9E2E3CE65E，SHA-256 B7C994A86BB61C91BB8A2F94CBAA33B9BC1C7FE97E646CA3DF38A49E964C9387。如果哪天出現憑證不同的「ATA」，請不要安裝。

一行安裝指令（curl -fsSL https://github.com/magiclin99/ata/releases/latest/download/install.sh | sh）會：

  1. 找到最新版本，下載 ATA-<版本>.zip 和它的 .sha256。
  2. 比對 SHA-256，再用 codesign --verify --deep --strict 對照固定的需求（bundle ID 加上憑證的 SHA-1）。不符就拒絕，什麼都不會安裝。
  3. 結束正在執行的 ATA，取代 /Applications/ATA.app（只有該資料夾無法寫入時才要求密碼），然後打開它。

用 curl 下載的檔案不會被加上 quarantine 屬性，所以 Gatekeeper 不會跳出提醒。想先看它會做什麼、不實際變更：… | sh -s -- --dry-run。建議先讀過指令稿：每個 release 都附有它，原始檔在 mac-app/install.sh。

網路使用與隱私

  • 沒有分析追蹤、沒有當機回報、沒有廣告、沒有帳號，也沒有開發者的伺服器。兩個 app 都不會傳任何東西給開發者。
  • 唯一的第三方接觸是 P2P 路徑上的 STUN 請求，Google 或 Cloudflare 會看到裝置的公開 IP 位址與連接埠。同一個 Wi-Fi 傳輸時完全不會連到網際網路。
  • Mac 版的「檢查更新…」只會在瀏覽器打開 Releases 頁面，沒有背景檢查更新。
  • Android 權限：BLUETOOTH_SCAN（宣告 neverForLocation）、BLUETOOTH_CONNECT；位置權限只在 Android 9–11 需要（系統規定 BLE 掃描要有）；CAMERA（只在掃描時）；網際網路與網路狀態；connectedDevice 類型的前景服務；通知。
  • Mac：藍牙、區域網路、一個接收連線的 listener（所以 macOS 應用程式防火牆可能會詢問）、通知、登入項目。

完整內容請看隱私權政策。

和其他方式比較

  • AirDrop 是 Apple 裝置之間的功能，ATA 不使用、也不連接 AirDrop。
  • 雲端硬碟和通訊軟體會把檔案上傳到某家公司的伺服器並留一份副本；ATA 直接傳送，除了收件的 Mac 之外不留任何副本。代價是兩台裝置必須在藍牙範圍內。
