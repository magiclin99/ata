Install ATA on your Mac

The Mac app is free and open source. It runs in the menu bar and receives the files your Android phone sends. It needs macOS 14 or later and runs natively on both Apple silicon and Intel Macs.

The Mac app is distributed through GitHub Releases, not the Mac App Store, and it isn't notarized by Apple. That's why a browser download needs one extra "Open Anyway" step. The one-line install below avoids it.

Option 1: one-line install (recommended)

Open Terminal (Applications → Utilities → Terminal), paste this line, and press Return:

curl -fsSL https://github.com/magiclin99/ata/releases/latest/download/install.sh | sh

The script finds the latest release on GitHub and downloads it with its SHA-256 checksum. It checks both the checksum and the app's code signature, and if either check fails it stops without installing anything. If ATA is already running, it quits it. Then it replaces /Applications/ATA.app, opens ATA, and prints each step as it goes. It asks for your password (sudo) only if your account can't write to /Applications. On a normal admin account it doesn't ask.

Files downloaded by curl aren't marked as "downloaded from the internet", so macOS doesn't show the warning described in option 2. Running the same line again later is also how you update.

To see what it would do without changing anything: curl -fsSL https://github.com/magiclin99/ata/releases/latest/download/install.sh | sh -s -- --dry-run

Prefer to read a script before running it? You should. Download it, look, then run it:

curl -fsSL https://github.com/magiclin99/ata/releases/latest/download/install.sh -o ata-install.sh
less ata-install.sh
sh ata-install.sh

Option 2: download in your browser

  1. Go to the latest release and download the .dmg (or the ATA-<version>.zip).
  2. Open the .dmg and drag ATA into Applications (or unzip the .zip and move ATA.app to Applications).
  3. Open ATA for the first time. The way to do it depends on your macOS version:

macOS 15 or later

  1. Double-click ATA in Applications. macOS says it can't verify ATA and won't open it. Click Done, not Move to Trash.
  2. Open System Settings → Privacy & Security and scroll down to the Security section. You'll see a message that "ATA" was blocked. Click Open Anyway.
  3. macOS asks once more. Click Open Anyway and confirm with your password or Touch ID.

The Open Anyway button appears only for about an hour after the blocked attempt. If it's missing, double-click ATA again, then go back to Privacy & Security.

macOS 14

  1. In Applications, Control-click (or right-click) ATA and choose Open.
  2. In the warning that appears, click Open.

You only do this once. After that, ATA opens normally.

Why the warning? Apple shows it for any app that isn't notarized through Apple's paid developer program. ATA's Mac app is a free, open-source project distributed outside the Mac App Store, so it isn't notarized. You can read or build the source yourself at github.com/magiclin99/ata.

First run

  1. Open ATA. Its window appears, and an ATA icon is added to the menu bar at the top of the screen. If you close the window, ATA keeps running in the menu bar. Open ATA again to bring the window back.
  2. Allow Bluetooth when macOS asks (see below).
  3. In ATA on the Mac, choose Pair New Device…. A QR code appears. It's valid for 5 minutes.
  4. On your Android phone, open ATA, tap Pair New Device…, and scan the code. The phone asks for camera access the first time you scan. If you'd rather not allow it, use Paste pairing link instead.
  5. Optional: turn on Launch at Login in ATA so it's always ready.

Permissions the Mac app asks for, and why

PermissionWhenWhy
Bluetooth (required)First launchLets your paired phone find this Mac nearby and exchange encrypted connection details. Without it, nothing works. If you clicked Don't Allow, use Open Bluetooth Privacy Settings… in the ATA menu.
Local NetworkFirst transfer (on macOS versions that ask)Receives files over your Wi-Fi, the fast path. If you deny it, transfers on the same Wi-Fi can't use the local network.
Accept incoming connectionsOnly if the macOS firewall is onThe phone connects to the Mac to deliver files. Click Allow.
Notifications (optional)After the first completed transferTells you when a file has arrived. Deny it and everything else still works.
Login Items (optional)When you turn on Launch at LoginStarts ATA when you log in. You can remove it in System Settings → General → Login Items.

The Mac app doesn't ask for Camera, Microphone, Location, Contacts, Full Disk Access, or Accessibility. It writes only to the save folder you choose (Downloads by default).

Updating and uninstalling

  • Update: run the one-line install again (it quits ATA, replaces it, and reopens it), or download the new release and replace ATA.app. Check for Updates… in the ATA menu opens the Releases page. ATA doesn't update itself or check in the background.
  • Uninstall: choose Quit ATA in the menu, then move ATA.app from Applications to the Trash. To remove the pairing keys too, choose Remove for each paired device in ATA before you quit it, or delete ATA's folder in ~/Library/Application Support/. Then remove the Mac on your phone as well.
